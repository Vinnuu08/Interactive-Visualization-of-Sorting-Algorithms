
# Interactive Visualization of Sorting Algorithms

## Project Description
This project is an interactive sorting algorithm visualizer.
It helps users understand how sorting algorithms work through animations.

## Algorithms Used
- Bubble Sort
- Selection Sort
- Insertion Sort

## Technologies Used
- Python
- Streamlit

## Features
- Generate random numbers
- Select sorting algorithms
- Visualize sorting animations
- Control animation speed
- Display time complexity

## How to Run
1. Install Python.
2. Install required library:
   pip install -r requirements.txt
3. Run the application:
   streamlit run app.py
